# Ether v0.3.15

## Console

- **Descriptive search waits long enough for the AI.** A search like "funny space movies" now waits up to 20 seconds for the AI, up from 10. Typical models answer a new descriptive query in 12–15 seconds, so the first search often showed only title matches. Title searches stay instant, and a repeated descriptive search answers from cache.
- **Editing an IPTV source while it refreshes works.** Saving changes to a source, such as its groups or a new guide file, while the same source was refreshing failed at once with "Couldn't import this source". A save now waits for the refresh to finish. When a source can't be imported, the console shows Ether's actual reason instead of a generic "Check the source settings".

## Live TV

- **Channel logos show in Plezy on iPhone, iPad and Apple TV.** Ether gave Plezy the logo address meant for Plex's own Apple apps, which Plezy can't load, so every logo was blank. Plezy now gets the same logos as on Android and the web.
